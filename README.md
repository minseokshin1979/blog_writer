# ✍️ AI 블로그 글 작성기

Google Gemini API를 활용하여 블로그 글을 자동으로 생성해주는 웹 애플리케이션입니다.

## 🌟 주요 기능

1. **키워드 기반 글 작성**: 원하는 주제의 키워드를 입력하면 관련 블로그 글을 작성합니다.
2. **관점 설정**: 작성자의 관점(초보자, 전문가 등)을 지정하여 글의 방향을 조절할 수 있습니다.
3. **스타일 커스터마이징**: 글의 스타일(친근하게, 진지하게, 정중하게 등)을 선택할 수 있습니다.
4. **다국어 지원**: 한국어, 영어, 일본어, 중국어, 스페인어로 블로그 글 생성 가능
5. **참고 자료 활용**:
   - 웹 링크에서 텍스트 추출
   - 파일 업로드 (txt, pdf, hwp 지원)
6. **결과물 저장**: 생성된 글을 마크다운(.md) 또는 텍스트(.txt) 형식으로 다운로드할 수 있습니다.

## 📋 요구사항

- Python 3.8 이상
- Google AI Studio API 키 (https://makersuite.google.com/app/apikey)

## 🚀 설치 방법

1. 레포지토리 클론 또는 파일 다운로드

2. 필요한 패키지 설치:
```bash
pip install -r requirements.txt
```

## 💻 사용 방법

1. 애플리케이션 실행:
```bash
streamlit run app.py
```

2. 브라우저에서 자동으로 열립니다 (보통 http://localhost:8501)

3. 사이드바에 Google AI Studio API 키를 입력합니다

4. 필수 항목 입력:
   - **키워드**: 블로그 글의 주제

5. 선택 항목 입력 (원하는 경우):
   - **작성자의 관점**: 글을 작성할 관점 (예: "초보자 입장에서", "전문가의 시각으로")
   - **글의 스타일**: 글의 톤과 스타일 (예: "친근하게", "20대를 위한")
   - **출력 언어**: 한국어, English, 日本語, 中文, Español 중 선택
   - **참고 자료**: 
     - 웹 링크: URL을 입력하고 "웹 내용 가져오기" 버튼 클릭
     - 파일: txt, pdf, hwp 파일을 업로드

6. "블로그 글 생성" 버튼을 클릭합니다

7. 생성된 글을 확인하고:
   - 텍스트 영역에서 복사하거나
   - 다운로드 버튼으로 파일로 저장

## 📁 파일 구조

```
.
├── app.py              # Streamlit 메인 애플리케이션
├── blog_generator.py   # LLM API 연동 모듈
├── file_parser.py      # 파일 파싱 모듈 (txt, pdf, hwp)
├── web_scraper.py      # 웹 스크래핑 모듈
├── requirements.txt    # 필요한 Python 패키지 목록
└── README.md          # 프로젝트 설명서
```

## 🔧 지원 파일 형식

- **텍스트 파일**: .txt
- **PDF 파일**: .pdf
- **한글 파일**: .hwp (HWP 5.0 이상)

## ⚙️ 모델 선택

사이드바에서 다음 Google Gemini 모델 중 하나를 선택할 수 있습니다:
- `gemini-2.5-flash` (기본값, 안정적이고 빠름, 1M 토큰 지원)
- `gemini-2.0-flash` (빠르고 효율적)
- `gemini-2.5-pro` (최고 성능, 긴 컨텍스트)
- `gemini-flash-latest` (항상 최신 버전)

## 📝 사용 예시

### 예시 1: 기본 사용
- **키워드**: "인공지능의 미래"
- **관점**: "기술 애호가의 관점에서"
- **스타일**: "흥미진진하게"

### 예시 2: 참고 자료 활용
- **키워드**: "건강한 식습관"
- **관점**: "영양사의 관점에서"
- **스타일**: "실용적이고 친근하게"
- **참고 자료**: 건강 관련 뉴스 기사 링크

## ⚠️ 주의사항

1. Google AI Studio API 사용에는 무료 할당량이 제공되며, 초과 시 요금이 부과될 수 있습니다.
2. API 키는 안전하게 보관하고 공유하지 마세요.
3. 웹 스크래핑은 사이트의 구조에 따라 결과가 다를 수 있습니다.
4. HWP 파일은 HWP 5.0 이상 형식만 지원됩니다.

## 🐛 문제 해결

### ImportError 발생 시
```bash
pip install -r requirements.txt --upgrade
```

### HWP 파일 읽기 오류
- HWP 5.0 이상 버전인지 확인해주세요
- 또는 HWP 파일을 PDF나 TXT로 변환하여 사용해주세요

### API 키 오류
- Google AI Studio API 키가 올바른지 확인해주세요
- https://makersuite.google.com/app/apikey 에서 확인 가능합니다
